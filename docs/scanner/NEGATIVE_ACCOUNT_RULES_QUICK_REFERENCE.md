# Negative Account Rules Quick Reference

Credit Vivo uses this internal quick reference to classify consumer credit report tradelines that may need review. It is not a guarantee that an item is inaccurate, removable, or legally actionable.

## Categories

- Collection
- Debt buyer
- Charge-off
- 30/60/90/120/150/180 day late
- Past due
- Repossession
- Voluntary surrender
- Foreclosure
- Bankruptcy
- Serious closed delinquency history
- Duplicate / overlapping debt review
- Outdated adverse information review

## Metro 2-Style Status Code Signals

- `71` = 30-59 days past due
- `78` = 60-89 days past due
- `80` = 90-119 days past due
- `82` = 120-149 days past due
- `83` = 150-179 days past due
- `84` = 180+ days past due
- `93` = collection
- `94` = foreclosure completed
- `95` = voluntary surrender
- `96` = repossession
- `97` = unpaid balance reported as loss / charge-off
- `62` = paid collection
- `64` = paid charge-off

## Compliance Guard

Use safe language: possible report error, possible inconsistency, review recommended, verify, correct/update/remove if unverifiable, results vary.

Do not use unsafe claims: violation proven, must delete, guaranteed removal, fix credit fast, lawsuit, automatic dispute.
